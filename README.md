# fb-clone-website

This project is a **Facebook website clone** that I built while learning and practicing Git and GitHub through a hands-on tutorial. The main goal of this project was to understand how a real-world website can be structured and to gain practical experience with version control and project management using Git.

The website is designed to replicate the basic look and feel of Facebook, including a familiar social-media-style layout, navigation elements, posts, user interactions, and other common UI components.

## 🚀 About the Project

This project was created as a learning exercise rather than as a production-ready social media platform. While building it, I focused on understanding how different parts of a website work together and how to manage the development process using Git.

It also gave me an opportunity to practice creating a project repository, making commits, tracking changes, and maintaining the project using Git and GitHub.

## 🎯 Learning Goals

Through this project, I practiced:

- Creating and managing a Git repository
- Making meaningful Git commits
- Tracking changes throughout development
- Working with Git and GitHub
- Understanding the basic workflow of a web development project
- Structuring files and folders for a website
- Recreating a familiar website interface for practice
- Improving my understanding of frontend development
